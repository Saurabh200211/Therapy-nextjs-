# Dr. Maya Reynolds Therapy — Next.js + Tailwind

Premium single-page therapy website created for the Grow My Therapy Front-End Developer Internship practical assignment.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Design direction

- Deep forest primary
- Warm sand secondary
- Muted terracotta accent
- Warm ivory background
- Editorial serif + clean sans-serif typography
- Responsive desktop/mobile layout
- Subtle reveal animations and image hover effects

## Image note

Dummy Unsplash images are intentionally used so the project runs immediately. They can be replaced later with the provided therapist and office images.
